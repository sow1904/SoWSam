성이나 거점을 끌어서 옮깁니다.

사용법

· 성(빨간 점)이나 거점(노란 표시)을 끌어서 옮깁니다. 옮긴 곳은 초록 테두리로 표시됩니다.
· 빈 곳을 끌면 지도가 움직이고, 휠로 확대·축소합니다.
· 선택한 곳은 방향키로 1px씩(Shift를 누르면 10px씩) 옮깁니다.
· Ctrl+Z로 되돌리고, Esc로 선택을 풉니다.
· 바꾼 위치는 이 브라우저에 자동으로 저장됩니다. 다 끝나면 「파일로 저장」을 눌러 받은 sowsam-positions.json을 알려 주세요. 「복사」로 내용을 붙여 넣어 주셔도 됩니다.
· 거리와 행군 일수는 실제 위경도로 재므로, 위치를 옮겨도 게임 밸런스는 바뀌지 않습니다.
